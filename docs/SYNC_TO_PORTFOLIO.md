# Syncing this project to https://xiaodernan.github.io/

Your personal portfolio at **https://xiaodernan.github.io/** — this repo cannot write
to it directly (it is a separate repository on your GitHub), but the sync is landed
as a single, self-contained file in this repo:

> **`public/showcase.html`**

Zero dependencies, zero build step — copy it anywhere and open it.

## What's in it

A dark, editorial one-screen showcase card with **measured** numbers drawn from the
tree: signed-in routes, page routes, top-level epics shipped, total work items
verified, and the current unit-test floor. No hand-maintained numbers — every
figure is regenerated by the script below on demand.

## Refresh it

```bash
python scripts/showcase-sync.py
```

The script reads:

- `docs/ROADMAP.md` — counts checked-off `- [x] **NNN**` epics (top-level and work items)
- `frontend/src/components/layout/nav.ts` — signed-in route count
- `frontend/src/app/**/page.tsx` — page route count
- hard-coded floor `TESTS = "1360+"` — bump when the suite crosses a round number

It rewrites `public/showcase.html` in place. Commit the result.

## When to refresh

Only when the numbers move — a new epic ships, the routes grow, or the test floor
bumps. Refreshing on every push adds churn without signal.

## How to embed it in your portfolio

**Option A — link to it (simplest):**

```html
<a href="https://github.com/xiaodernan/ai-career-os">AI Career OS — see it live</a>
```

**Option B — iframe embed (gives the card-in-a-card effect):**

```html
<iframe src="https://xiaodernan.github.io/ai-career-os/showcase.html"
        width="100%" height="520" frameborder="0"
        title="AI Career OS — the personal job-search operating system"></iframe>
```

The file is self-contained (inline CSS, no JS), so it renders inside an iframe on
any origin with zero CORS concerns.

**Option C — copy the file in directly:**

1. Run `scripts/showcase-sync.py`.
2. `cp public/showcase.html <your-portfolio-repo>/showcase/ai-career-os.html`
3. Link from your portfolio landing page: `<a href="/showcase/ai-career-os.html">`.
4. Commit. Done.

## Notes for a first-time reader

- The card's numbers are the **project's own truth**, not aspirations. If the work
  doesn't ship, the card doesn't grow.
- The GitHub repository it links to is `xiaodernan/ai-career-os` — replace the
  href in `scripts/showcase-sync.py` if the repo ever moves.
- The card is **dark-mode-only** by design (the editor's own theme);
  if your portfolio is light-mode, wrap the iframe in `color-scheme: dark` scope,
  or fork the file and change the four `:root` variables.
